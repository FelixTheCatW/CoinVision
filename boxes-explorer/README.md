# boxes-explorer

Разметка четырёхугольников вокруг года на фотографиях монет: объединяет просмотрщик
`img-explorer` (четыре точки, маска, масштаб 1:1) и таблицу из `sheet-explorer`.
Работает с `data/annotations/date_boxes.csv`.

## Возможности

- При запуске загружается `data/annotations/date_boxes.csv` (файл ищется вверх по каталогам
  от папки с exe, поэтому программу нужно запускать внутри проекта CoinVision).
- Таблица справа: `image`, `box` (x1,y1 … x4,y4), `kind`, `year`; `kind` редактируется,
  остальные колонки — только для чтения.
- Выделение строки сразу открывает изображение из колонки `image` в масштабе **1:1**
  (без вписывания в окно, с прокруткой). Если в строке уже есть координаты, маска
  сразу рисуется поверх картинки.
- Четыре нажатия `Q` запоминают пиксель под курсором (точка 1, 2, 3, 4). После четвёртой
  точки координаты записываются в колонки `x1…y4` этой строки и копируются в буфер обмена
  одной строкой `x1,y1,x2,y2,x3,y3,x4,y4`.
- `1` — `kind = engraved`, `2` — `kind = slab`; после этого выделение переходит на строку ниже.
- `↑` / `↓` — предыдущая/следующая строка (таблица и картинка переключаются сразу).
- `Ctrl+S` или кнопка «Сохранить» — запись файла. Пока есть несохранённые изменения,
  в статусе написано «Не сохранено…», при закрытии окна предлагается сохранить.
- `Esc` — снять черновик области (сохранённые координаты строки не меняются).
- Маска: пунктир от последней точки к курсору, замкнутый четырёхугольник после четырёх
  точек, маркеры с номерами. Пятое нажатие `Q` начинает новую область.
- Изображение декодируется через SkiaSharp (png, jpg/jpeg, webp, gif; у gif первый кадр,
  EXIF-ориентация JPEG учитывается).

## Сборка и запуск

```powershell
dotnet run --project boxes-explorer
```

или

```powershell
dotnet build boxes-explorer
boxes-explorer\bin\Debug\net8.0-windows\BoxesExplorer.exe
```

Требуется .NET 8 SDK.

## Формат файла

`data/annotations/date_boxes.csv`, разделитель `,`:

```
image,x1,y1,x2,y2,x3,y3,x4,y4,kind,year
data/source/...jpg,1326,666,1462,562,1500,600,1367,729,engraved,1832
```

- Координаты — целые пиксели исходного изображения, порядок по часовой стрелке от левого
  верхнего угла читаемого года: `x1,y1` — верхний левый, `x2,y2` — верхний правый,
  `x3,y3` — нижний правый, `x4,y4` — нижний левый.
- Пустые ячейки `x1..y4` означают, что область ещё не размечена.
- Остальные колонки, кодировка, переводы строк и порядок строк сохраняются как были;
  запись идёт через временный файл.

## Управление

| Действие | Клавиши / мышь |
| --- | --- |
| Выбрать строку | клик, `↑` / `↓` |
| Запомнить точку области | `Q` (курсор над картинкой) |
| `kind` = `engraved` + переход ниже | `1` (или NumPad 1) |
| `kind` = `slab` + переход ниже | `2` (или NumPad 2) |
| Правка `kind` вручную | двойной клик по ячейке, `F2` |
| Сохранить файл | `Ctrl+S` или кнопка «Сохранить» |
| Снять черновик области | `Esc` |

## Замечания

- 1:1 — это 100 % в логических пикселях WPF: один пиксель изображения = один DIP.
- Заголовок окна показывает имя открытого изображения, строка состояния — номер строки,
  путь, размер в пикселях, координаты курсора и всех четырёх точек.
- При запуске выделяется первая строка без размеченной области (если такие есть).
- Если изображение не найдено, слева выводится сообщение, строку всё равно можно править.
