# AGENTS.md

## Правила работы (обязательно)

- **Не писать код и не создавать/изменять файлы по своей инициативе.**
- Любые изменения — только по явной просьбе пользователя или с его разрешения.
- Сначала предложить план/вариант и дождаться ознакомления и подтверждения пользователя, и только после этого выполнять.
- Не расширять объём задачи самостоятельно; не делать рефакторинг и «улучшения» без запроса.

## Команды проекта

- Установка окружения: `uv sync --extra dev`
- Тесты: `uv run pytest`
- Линт: `uv run ruff check .`
- Типы: `uv run mypy src/coinvision`

## Длительные операции

- Перед запуском любой операции длиннее пары минут сообщать три вещи: время начала по локальным
  часам, оценку длительности и предполагаемое время окончания (например: «начало 14:32, ~35 мин,
  ориентировочно до 15:07»).
- По завершении воспроизводить звуковой сигнал, чтобы результат не приходилось ждать глазами.
  Уведомление агента (`notify`) приходит в чат, но не звучит — сигнал должен идти из самой команды:

      <длинная команда> ; powershell -NoProfile -Command "[console]::beep(1000,250); [console]::beep(1500,350)"

- Если процесс уже запущен, звук ставится отдельным сторожем по PID (см. `scratch/watch_beep.ps1`
  в рабочей сессии), а не переносом команды.

## Контекст

- Python 3.12, PyTorch CUDA 12.6 (GTX 1050 Ti / Pascal sm_61; cu128+ не поддерживают Pascal).
