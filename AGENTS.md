# AGENTS.md

## Правила работы (обязательно)

- **Не писать код и не создавать/изменять файлы по своей инициативе.**
- Любые изменения — только по явной просьбе пользователя или с его разрешения.
- Сначала предложить план/вариант и дождаться ознакомления и подтверждения пользователя, и только после этого выполнять.
- Не расширять объём задачи самостоятельно; не делать рефакторинг и «улучшения» без запроса.

## Команды проекта

- Установка окружения: `uv sync --extra dev`
- Тесты: `uv run pytest`
- Линт: `uv run ruff check .`
- Типы: `uv run mypy src/coinvision`

## Контекст

- Python 3.12, PyTorch CUDA 12.6 (GTX 1050 Ti / Pascal sm_61; cu128+ не поддерживают Pascal).
