# sheet-explorer

Просмотр и разметка `data/annotations/verdict/verdict.csv` на C# / WPF (.NET 8).

Слева — изображение выбранной строки в масштабе **1:1** (без вписывания в окно, с прокруткой),
справа — таблица с колонками `image`, `kind`, `note` из CSV-файла.

## Возможности

- При запуске автоматически загружается `data/annotations/verdict/verdict.csv`
  (файл ищется вверх по каталогам от папки с exe, поэтому программа должна запускаться
  внутри каталога проекта CoinVision).
- Выделение строки таблицы сразу показывает изображение из первой колонки.
  Путь (`data/source/...`) разрешается относительно корня проекта.
- Изображение выводится 1:1: один пиксель картинки = один DIP, без масштабирования
  и растягивания; при нехватке места появляются полосы прокрутки.
- `kind` и `note` правятся вручную: двойной клик по ячейке (или `F2`) — редактирование,
  `Enter`/`Tab` — фиксация.
- Оба поля — редактируемые выпадающие списки:
  - `kind` предлагает `engraved`, `slab` и все значения, уже встречающиеся в файле;
  - `note` предлагает уже введённые в файле комментарии.
  В обоих можно вписать произвольный текст, в том числе пустое значение.
- Клавиши `1` и `2` при выделенной строке ставят в `kind` значение `engraved` или `slab`
  и сразу сохраняют файл, после чего выделение переходит на следующую строку — удобно
  для быстрой последовательной разметки.
- Любое изменение автоматически записывается в CSV (примерно через 0,4 с после последней
  правки), дополнительно сохраняется по `Ctrl+S`, при смене строки и закрытии окна.
  Файл перезаписывается целиком с сохранением порядка строк, кодировки, переводов строк
  и лишних колонок (если они есть). Запись идёт через временный файл, чтобы не оставить
  файл недописанным.
- Значения с запятыми и кавычками корректно экранируются.
- Тёмная тема, изображение декодируется через SkiaSharp (png, jpg/jpeg, webp, gif;
  у gif — первый кадр, EXIF-ориентация JPEG учитывается — WPF сам webp не открывает).

## Сборка и запуск

```powershell
dotnet run --project sheet-explorer
```

или

```powershell
dotnet build sheet-explorer
sheet-explorer\bin\Debug\net8.0-windows\SheetExplorer.exe
```

Требуется .NET 8 SDK (для запуска готовой сборки — Desktop Runtime).

## Управление

| Действие | Клавиши / мышь |
| --- | --- |
| Выбрать строку | клик по строке, стрелки ↑/↓ |
| Редактировать `kind` / `note` | двойной клик по ячейке или `F2` |
| Подтвердить правку | `Enter` / `Tab` |
| `kind` = `engraved` и переход ниже | `1` (или NumPad 1) |
| `kind` = `slab` и переход ниже | `2` (или NumPad 2) |
| Отменить незавершённую правку | `Esc` |
| Сохранить немедленно | `Ctrl+S` или кнопка «Сохранить» |
| Прокрутить изображение | колесо мыши / полосы прокрутки |

## Замечания

- 1:1 — это 100 % в логических пикселях WPF: один пиксель изображения равен одному DIP.
  При масштабе Windows 125/150 % физический размер пикселя на экране пропорционально больше.
- Ширина правой панели меняется перетаскиванием разделителя; ширину колонок таблицы
  можно менять, потянув за границу заголовка.
- Если файл изображения не найден, слева выводится сообщение, а строка остаётся доступной
  для правки.

## Зависимости

`SkiaSharp` — декодер изображений. Нативные библиотеки приходят с пакетом (папка `runtimes`
в сборке).
