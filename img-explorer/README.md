# img-explorer

Небольшой просмотрщик изображений на C# / WPF (.NET 8) для быстрого снятия координат
области на изображении.

## Возможности

- Открытие файлов **png, jpg/jpeg, webp, gif** — кнопкой «Открыть…» или клавишей `W`
  (у gif показывается первый кадр).
- Изображение выводится в масштабе **1:1** (без вписывания в окно), с прокруткой.
- Четыре точки области задаются последовательно: каждое нажатие `Q` запоминает
  пиксель под курсором (точка 1, 2, 3, 4).
- После четвёртой точки координаты автоматически копируются в буфер обмена
  одной строкой через запятую без пробелов:
  `x1,y1,x2,y2,x3,y3,x4,y4` (например `7,16,15,2,18,4,10,18`).
- Поверх изображения рисуется маска — четырёхугольник по заданным точкам
  (подходит и для повёрнутых областей). Точки помечены перекрестиями с номерами.
  Пока точек меньше четырёх, следующая сторона показывается пунктиром от последней
  точки до курсора (а когда точек три — ещё и замыкающая сторона).
- Пятое нажатие `Q` начинает новую область (старые точки забываются).
- `W` — открыть другое изображение, `Esc` — снять область и забыть все точки.
- В строке состояния видны координаты курсора и всех четырёх точек.

## Сборка и запуск

```powershell
dotnet run --project img-explorer
```

или

```powershell
dotnet build img-explorer
img-explorer\bin\Debug\net8.0-windows\ImgExplorer.exe
```

Требуется .NET 8 SDK (Desktop Runtime для запуска готовой сборки).

## Зависимости

`SkiaSharp` — декодер изображений (png/jpg/webp/gif). WPF не умеет открывать webp
из коробки, поэтому декодирование выполняется одним движком для всех форматов.
Нативные библиотеки SkiaSharp приходят с пакетом (папка `runtimes` в сборке).

## Замечания

- Координаты отсчитываются от левого верхнего пикселя изображения: `(0, 0)` — первый пиксель.
- Точки соединяются в том порядке, в котором нажаты: обходите углы области
  по периметру (например, по часовой стрелке), иначе маска самопересечётся.
- В буфер обмена попадают целые числа через запятую без пробелов.
- 1:1 — это 100 % в логических пикселях WPF, т.е. один пиксель изображения
  равен одному DIP. При масштабе Windows 125/150 % физический размер пикселя
  на экране пропорционально больше.
- Ориентация JPEG по EXIF учитывается.
