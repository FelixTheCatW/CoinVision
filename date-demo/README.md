# date-demo — «есть ли на монете дата»

Демонстрационное приложение: C# (ASP.NET, minimal API) + Vue 3, всё в одном процессе — API
раздаёт собранный фронтенд из своего `wwwroot`.

На входе — фотография монеты, на выходе:

  - **вердикт «дата есть / даты нет»** — по максимальной вероятности скорера окон;
  - **вырезанная область** — кроп окна, которое скорер выбрал лучшим (PNG, 160×80);
  - **фото с разметкой** — найденные круги монет и выбранное окно поверх оригинала;
  - **технические показатели** — время по стадиям, число монет и окон, пять лучших окон.

Классификатора года здесь нет намеренно: используется только скорер окон
(`onnx/window_scorer.onnx`). 4-значная модель из 5-фолдового CV (`onnx/coinvision_*.onnx`)
в этом приложении не подключена.

## Как это работает

    decode      SkiaSharp декодирует файл
    detect      порт `coinvision.localize.detect_coins`: размытие σ=1.2, градиенты,
                порог по 96-му процентилю, голосование по 20 радиусам в обе стороны,
                размытие аккумулятора σ=3, аргмакс + подавление, радиус по самому внешнему
                сильному пику радиального профиля (обод, а не щит внутри него)
                кандидат без сплошного обода (надпись, водяной знак, край слаба) отбрасывается
                по rim score ≥ 0.12, вместо него ищется следующий пик
    sweep       кольцо размечается окнами: дуга 110°, шаг 24°, полоса 0.32–1.02 радиуса
    crop        каждое окно разворачивается в 160×80 (аффинное преобразование, Skia, Catmull-Rom)
    score       ONNX-скорер (3×80×160 → один логит → sigmoid): «год целиком внутри окна»

Порог вердикта — 0.5. Полное время на фото 1600×790 — около 1.0–1.4 с, из них ~0.6 с на поиск
монет.

## Запуск

    # фронтенд (один раз и после правок)
    cd frontend
    npm install
    npm run build          # собирает в ../api/CoinVision.DateApi/wwwroot

    # сервис
    cd api/CoinVision.DateApi
    dotnet run --urls http://127.0.0.1:5199

Открыть http://127.0.0.1:5199/. Фото можно перетащить, выбрать через диалог или вставить из
буфера — Ctrl+V в любом месте страницы (из системного скриншота, из просмотрщика картинок и т. п.).

Для разработки фронтенда: `npm run dev` (Vite проксирует `/api` на 5199).

## API

    GET  /api/info     — параметры модели и геометрии окон
    GET  /api/health
    POST /api/detect   — multipart/form-data, поле `file` (или любой первый файл),
                         опционально ?window=N — принудительно вернуть кроп окна N

Ответ `DetectResponse`:

    ok, error, fileName, sizeBytes, width, height
    hasDate, bestScore, threshold
    cropPng, previewPng            — base64 PNG
    cropWidth, cropHeight, coins[], windowCount, topWindows[], timingMs{decode,detect,sweep,crop,score,total}

## Известные ограничения

- Слабы: год напечатан на этикетке, а не на кольце, поэтому скорер может выдать ложное «дата
  есть». Слабы вне области задачи — кольцевая сетка их не моделирует.
- Кроп окна — это широкий сектор (110° дуги), а не плотная рамка вокруг года: год может оказаться
  у края и быть повёрнутым на десятки градусов. Это ограничение текущей разметки «containment»,
  а не порта.
- Время поиска монет (~0.6 с) — узкое место; при необходимости оптимизируется переносом
  голосования и размытия на меньший масштаб.
